# Project Guidelines & Active Skills: Escuela Ombú

This project uses modern frontend design skills and design systems to deliver world-class craft, fluid motion, and high-impact visual design for **Escuela Ombú** (water sports: kitesurf, windsurf, SUP, wingfoil).

## Active Skills (.agent/skills)
The following skills are installed and active for this project:

- **impeccable** (`.agent/skills/impeccable/SKILL.md`):
  Enforces 61 deterministic detector rules, high craft standards, visual hierarchy, clarity, and design refinement commands (`craft`, `shape`, `critique`, `audit`, `polish`, `bolder`, `quieter`, `distill`, `animate`, `delight`, `harden`).
- **emil-design-eng** (`.agent/skills/emil-design-eng/SKILL.md`):
  Expert frontend engineering and interaction guidelines by Emil Kowalski (Vercel, Linear).
- **apple-design** (`.agent/skills/apple-design/SKILL.md`):
  Apple's principles for fluid motion, depth, and clean interface aesthetics translated to the web.
- **animate** (`.agent/skills/animate/SKILL.md`):
  Purposeful motion, proper easing curves, physics, and durations.
- **review-animations**, **improve-animations**, **find-animation-opportunities**:
  Motion audits and enhancements.
- **mobile-native** (`.agent/skills/mobile-native/SKILL.md`):
  Native-feeling mobile responsiveness, touch targets, and viewport optimizations.

## Design Systems & Reference Worlds (.agent/design-systems)
Contains durable `DESIGN.md` guidelines for 70+ leading design systems (e.g. `apple`, `linear.app`, `airbnb`, `stripe`, `vercel`, `supa-base`, etc.) available in `.agent/design-systems/<brand>/DESIGN.md`.

## Core Standards
1. **No generic AI slop**: Avoid boring default Inter typography, uninspired purple gradients, nested cards, and gray text with poor contrast.
2. **Authentic identity**: Refine the visual identity for Escuela Ombú to convey nature, water, wind, adventure, high-performance coaching, and warm community vibes.
3. **Fluid performance**: Optimize assets, use modern CSS (clamp, subgrid, container queries, backdrop filters), and ensure 60fps animations.
